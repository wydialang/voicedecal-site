{%- comment -%} Top-bar theme controls. THEME SETS, each a light + dark pair, are defined in _sass/color_schemes/ and exposed as stylesheets by assets/css/. - the button flips light <-> dark within the current set - clicking the site logo cycles set 1 -> 2 -> 3 (keeping light/dark) - the choice is saved in the browser (localStorage "jtd-theme"); until the visitor picks something, the light/dark half follows their OS setting {%- endcomment -%}
